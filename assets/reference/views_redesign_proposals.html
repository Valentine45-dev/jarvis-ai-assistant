JARVIS — View Redesigns (Voice · Automation · History · Settings · Terminal)

Five tabs redesigned to match the same principles applied to the dashboard: typography hierarchy, intent badges, divide-y rows instead of card framing where density warrants, active-vs-passive panel borders, off-center weight where it makes sense. All rendered in the Stark Cyan theme (default); the other four themes apply on top by token-swap.

SHIP NOTES: every view applies the same design grammar — top hero stats, divide-y rows instead of card framing, active-vs-passive panel borders, intent badges, typography hierarchy. Same look across the app. Themes (Stark Cyan default + Teal · Amber · Indigo · Matrix) work via token swap on top of any view. Layout choice (Bento / Polish / Centered / Minimalist on the dashboard) is independent of view-level redesign — these mockups assume the Bento dashboard but the chrome (border treatment, typography, badges) is identical regardless.
